# Sistem Keuangan Digital

## Deskripsi Proyek

Sistem Keuangan Digital merupakan aplikasi berbasis web yang dirancang untuk membantu pengguna dalam mengelola keuangan pribadi secara lebih efektif dan terstruktur. Melalui aplikasi ini, pengguna dapat mencatat anggaran, mengelola tabungan, serta memantau kondisi keuangan mereka dalam satu platform yang terintegrasi.

Proyek ini dikembangkan menggunakan framework Spring Boot dengan database MySQL sebagai media penyimpanan data. Antarmuka pengguna dibangun menggunakan Thymeleaf sehingga menghasilkan tampilan yang responsif dan mudah digunakan.

## Tujuan Proyek

Tujuan dari pengembangan Sistem Keuangan Digital adalah:

* Membantu pengguna mengelola keuangan secara lebih terorganisir.
* Mempermudah pencatatan anggaran dan tabungan.
* Menyediakan informasi keuangan yang mudah dipahami.
* Meningkatkan kesadaran pengguna terhadap kondisi keuangan pribadi.

## Fitur Utama

* Registrasi dan Login Pengguna
* Manajemen Data Anggaran
* Manajemen Data Tabungan
* Pengelolaan Profil Pengguna
* Penyimpanan Data Berbasis Database MySQL
