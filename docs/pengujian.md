# Pengujian Sistem

[⬅ Kembali ke Beranda](index.md)

Pengujian dilakukan untuk memastikan seluruh fitur pada Sistem Keuangan Digital dapat berjalan sesuai dengan kebutuhan pengguna.

## Hasil Pengujian

| No | Skenario Pengujian            | Hasil yang Diharapkan       | Status   |
| -- | ----------------------------- | --------------------------- | -------- |
| 1  | Registrasi akun baru          | Data berhasil disimpan      | Berhasil |
| 2  | Login dengan data valid       | Pengguna masuk ke dashboard | Berhasil |
| 3  | Login dengan data tidak valid | Muncul pesan kesalahan      | Berhasil |
| 4  | Menambah data anggaran        | Data tersimpan ke database  | Berhasil |
| 5  | Mengubah data anggaran        | Data berhasil diperbarui    | Berhasil |
| 6  | Menghapus data anggaran       | Data berhasil dihapus       | Berhasil |
| 7  | Menambah data tabungan        | Data tersimpan ke database  | Berhasil |
| 8  | Mengubah data tabungan        | Data berhasil diperbarui    | Berhasil |
| 9  | Menghapus data tabungan       | Data berhasil dihapus       | Berhasil |
| 10 | Logout sistem                 | Pengguna keluar dari sistem | Berhasil |

## Kesimpulan Pengujian

Berdasarkan hasil pengujian yang telah dilakukan, seluruh fitur utama pada Sistem Keuangan Digital dapat berjalan sesuai dengan kebutuhan pengguna. Tidak ditemukan kesalahan kritis yang menghambat fungsi utama aplikasi.
